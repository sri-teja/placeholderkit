Guide · Fake data

Mock ecommerce data: customers, products and orders

createWorld() builds a whole fake store in one call, with customers, products, orders, reviews and monthly revenue where every total adds up, and you can export it as JSON, CSV or SQL.

Store type
Terminal 
npm install @placeholderkit/core
import { createWorld } from "@placeholderkit/core/data";

const store = createWorld({ seed: "demo", industry: "ecommerce" });

store.products;   // 24 products with imageUrl, price, stock, rating
store.customers;  // 25 customers with avatarUrl, email, address
store.orders;     // 98 orders; total = subtotal + tax + shipping
store.customer(store.orders[0].customerId);

The code follows the seed and store type. The store on the right is its output.

Export it to a database or a file

Records are plain JSON, so you can pass them straight to components or an API mock. To seed a database, turn the same world into SQL inserts for Postgres, MySQL or SQLite, or into one CSV per table.

seed.js 
import { writeFileSync } from "node:fs";
import { createWorld, toSQL, toCSV } from "@placeholderkit/core/data";

const store = createWorld({ seed: "demo", industry: "ecommerce", size: "medium" });

writeFileSync("seed.sql", toSQL(store, { dialect: "postgres" }));  // or "mysql", "sqlite"
const tables = toCSV(store);  // { customers: "id,first_name,...", orders: "...", ... }

Good to know

Do I get different data every run?

No. The same seed and options always give the same store, so tests and screenshots stay stable. Change the seed for a different store. Customer and product i stay the same when you change size.

How big can it get?

size: "small" has 25 customers, "medium" 500 and "large" 5,000, with orders and reviews to match.

What makes it realistic?

Every reference points to a real record, money is in integer cents and adds up exactly, nothing happens before the store was founded, order status matches its age, reviews come after delivery, and revenue grows with a holiday peak.

Other countries, currencies or a SaaS business?

Set locale (en-US, en-GB, en-IN) and currency (USD, GBP, EUR, INR). Use industry: "saas" for accounts, plans, invoices and activity instead. Try the SaaS version on the homepage.
