Placeholder images in Next.js, without external URLs

<Placeholder> draws product, food, travel and other content images as inline SVG, so they render in Server Components with no next.config.js changes and no network requests.

26 categories in all. Browse them in the explorer.

1. Install

Terminal 
npm install @placeholderkit/core

2. Use it in a page

app/page.jsx 
import { Placeholder } from "@placeholderkit/core/react";

export default function Page() {
  return (
    <div style={{ display: "grid", gridTemplateColumns: "repeat(3, 1fr)", gap: 16 }}>
      {["product-1", "product-2", "product-3"].map((id) => (
        <Placeholder key={id} seed={id} category="product" ratio="4/3" />
      ))}
    </div>
  );
}

This is a Server Component: no "use client" needed. The code follows the category and ratio you pick; the images on the left are its output.

Why not a placeholder URL service?

Hosted placeholder URLs are fine until they aren't. With next/image each image host has to be allowed in images.remotePatterns in next.config.js, and every image is a request to someone else's server: slow on a cold cache, broken offline, in CI and in sandboxed preview environments, and gone if the service changes.

<Placeholder> renders a plain <img> whose source is an SVG data URL, about 1.5 KB per image in the HTML. There is no host to configure and nothing to fetch, and the same seed always gives the same picture, so server and client render identical markup.

Hero images, captions and plain URLs

Add a label to draw a caption on the image, or use placeholderUrl() where you need a string, such as a CSS background or an existing image component.

app/hero.jsx 
import { Placeholder } from "@placeholderkit/core/react";
import { placeholderUrl } from "@placeholderkit/core";

export function Hero() {
  return <Placeholder seed="home-hero" category="travel" ratio="21/9" label="Hero image" />;
}

export function Banner() {
  const bg = placeholderUrl({ seed: "banner", category: "food", ratio: "3/1" });
  return <section style={{ backgroundImage: `url("${bg}")`, backgroundSize: "cover" }} />;
}

Good to know

Does it work with the App Router and Server Components?

Yes. The React components use no hooks or browser APIs, so they render in Server Components, during SSR and on the client, with the same output everywhere.

How do I swap in real images later?

Replace <Placeholder> with your image or next/image and keep the same aspect ratio, so the layout doesn't move. Use a stable seed such as the product id so each slot keeps its picture until then.

Does it work without React?

Yes. placeholderUrl() works in any framework, and a script tag fills <img data-placeholderkit="placeholder"> in plain HTML. See the README.

Can I use it in a commercial project?

Yes. placeholderkit is MIT licensed.
