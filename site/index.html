      Why placeholderkit
      
        
      Built for the first draft.
      
        
      Prototypes need images long before anyone has the real ones. placeholderkit fills every slot with something that fits.
      
      
      
      
      
        
      
          
      
          
      Same seed, same image
      
          
      Pass a user id, email or slug. You get the same picture on every render, on the server and in the browser. Default avatars from a user ID in React
      
        
      
        
      
          
      
          
      No network, ever
      
          
      Images are drawn as SVG in your code. Nothing to host, no broken links, and it works offline, in sandboxes and in CI.
      
        
      
        
      
          
      
          
      Works with your stack
      
          
      React components that run in Server Components, a script tag for plain HTML, or functions that return image URLs.
      
        
      
        
      
          
      
          
      Small and accessible
      
          
      Import only what you use, about 2–4 KB each. Every image ships with sensible alt text.

      Questions
      
        
      Good to know
      
      
      
      
      
        
      Is it free to use?
      Yes. placeholderkit is open source under the MIT license, for personal and commercial projects.
      
        
      Does it load images from a server?
      No. Every image is generated as SVG by the package itself and returned as a data URL. There are no requests, so it works offline and never breaks.
      
        
      What should I use as the seed?
      Anything stable that identifies the thing being shown: a user id, an email, a product slug. The same seed always gives the same image, so lists don't reshuffle between renders. How to give every user a default avatar from their ID in React.
      
        
      Does it work with Next.js Server Components?
      Yes. The React components use no hooks or browser APIs, so they render in Server Components, during SSR and on the client. Placeholder images in Next.js, step by step.
      
        
      Which icons can I use?
      <Icon name="shopping-cart" /> takes any Lucide icon name and shows a fallback for unknown names. It needs lucide-react installed.
