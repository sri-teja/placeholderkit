Default avatars from a user ID or email, in React

Pass a user's ID or email to <Avatar> and every account without a profile picture gets its own avatar, the same one on every render, with no network requests.

Same input, same avatar, at any size.

Shape
Example users: click one

1. Install

Terminal 
npm install @placeholderkit/core

2. Render the avatar

import { Avatar } from "@placeholderkit/core/react";

<Avatar seed="ana@acme.com" size={48} alt="Ana Silva" />

The code updates as you type or pick a user. Output: the avatar on the left, as an inline SVG data URL.

In a real app: photo first, generated avatar as the fallback

Most apps have a photo for some users and nothing for the rest. Use the photo when there is one and generate the avatar from the user's ID otherwise. avatarUrl() returns a string, so it slots into an existing <img> or an avatar component from your UI library.

UserAvatar.jsx 
import { avatarUrl } from "@placeholderkit/core";

export function UserAvatar({ user, size = 40 }) {
  return (
    <img
      src={user.photoUrl ?? avatarUrl({ seed: user.id })}
      alt={user.name}
      width={size}
      height={size}
      style={{ borderRadius: "50%" }}
    />
  );
}

Good to know

Should I use the ID or the email?

Prefer the user ID: it never changes, while people do change their email. The seed is used exactly as given, so if you use emails, trim and lower-case them first so Ana@Acme.com and ana@acme.com get the same avatar.

Does it call a service like Gravatar?

No. The avatar is drawn as SVG by the package and returned as a data URL. Nothing is fetched, nothing leaves the browser, and it works offline and in tests.

Does it work in Next.js Server Components?

Yes. <Avatar> uses no hooks or browser APIs, so it renders in Server Components, during SSR and on the client, with the same output everywhere.

Can I get animals or other styles instead?

Use <AnimalAvatar seed={user.id} /> for animal characters, and artStyle="flat" or "outlined" to change the drawing style. See every option in the explorer.
