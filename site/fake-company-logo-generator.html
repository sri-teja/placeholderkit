Fake company logos and names for mockups

Type any text and get a believable company name with a matching logo, the same one every time, for logo strips, customer tables and dashboards.

A logo strip from six seeds: click one

Terminal

import { Logo } from "@placeholderkit/core/react";

<Logo seed="northwind" height={40} />
<Logo seed="northwind" variant="mark" height={56} />

A "trusted by" logo strip

Give each customer a stable id as the seed. The name in each logo is generated from it, or pass name to use your own.

TrustedBy.jsx 
import { Logo } from "@placeholderkit/core/react";

const customers = ["northwind", "globex", "initech", "umbrella", "hooli", "vandelay"];

export function TrustedBy() {
  return (
    <div style={{ display: "flex", flexWrap: "wrap", gap: 32, alignItems: "center" }}>
      {customers.map((id) => <Logo key={id} seed={id} height={24} />)}
    </div>
  );
}

Good to know

Are these real companies?

No. Names are put together from word lists, such as {{COMPANY:globex}} or {{COMPANY:initech}}. A generated name can still happen to match a real business, so check before using one anywhere public.

What can I change?

The name in the wordmark, the variant ("full" for mark and name, "mark" for the symbol alone), the mark's color and the height. The width follows the name's length.

Will they work on a dark background?

The wordmark text is dark, so put full logos on a light surface, or use variant="mark" on dark backgrounds.

Can I get a whole fake customer list with logos?

Yes. createWorld() builds connected fake business data, and its SaaS accounts come with logos already attached.
